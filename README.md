# 📊 Business Sales & Profit Analytics — SQL

## 📌 Project Overview

**Business Sales & Profit Analytics** is an end-to-end SQL analytics project focused on analyzing business performance across different business types, cities, ownership structures, customer bases, and payment methods.

The project uses SQL Server to transform business data into meaningful business insights using filtering, aggregation, subqueries, `CASE WHEN`, CTEs, window functions, ranking, date analysis, and advanced SQL techniques.

The goal is to answer practical business questions such as:

* Which businesses generate the highest profit?
* Which business types have the highest total sales and profit?
* Which cities perform best?
* Which businesses perform above their business-type average?
* Which businesses have the highest sales per customer or employee?
* What percentage of a business type's total profit is generated by each business?
* Which businesses rank in the top 3 within their city or business type?
* Which business type has the highest total profit?
* Which city has the highest average business profit?

# 2️⃣ Aggregation & Business Performance

The project analyzes business performance by:

* Business Type
* City
* Business Size
* Ownership Type
* Payment Method

### Key Metrics

* Total Sales
* Total Expenses
* Total Profit
* Average Profit
* Number of Businesses
* Total Employees
* Total Customers
* Average Customer Satisfaction

### Example

```sql
SELECT
    Business_Type,
    SUM(Sales) AS TotalSales,
    SUM(Expenses) AS TotalExpenses,
    SUM(Profit) AS TotalProfit,
    AVG(Profit) AS AverageProfit,
    COUNT(*) AS NumberOfBusinesses
FROM business_data
GROUP BY Business_Type;
```

# 3️⃣ Subquery Analysis

Subqueries are used to compare individual businesses against overall business performance.

### Examples

* Businesses above average Profit
* Businesses above average Sales
* Business with maximum Profit
* Businesses with maximum Sales within each Business Type
* Businesses above average Customers

### Example

```sql
SELECT
    Business_Name,
    Business_Type,
    City,
    Profit
FROM business_data
WHERE Profit > (
    SELECT AVG(Profit)
    FROM business_data
)
ORDER BY Profit DESC;
```

# 5️⃣ KPI & Ratio Analysis

The project calculates several business KPIs.

## Profit Margin

```text
Profit Margin = Profit / Sales × 100
```

Example:

```sql
SELECT
    Business_Name,
    Sales,
    Profit,
    Profit * 100.0 / NULLIF(Sales, 0) AS Profit_Margin
FROM business_data
ORDER BY Profit_Margin DESC;
```

## Sales per Employee

```text
Sales per Employee = Sales / Employees
```

## Sales per Customer

```text
Sales per Customer = Sales / Customers
```

## Profit per Branch

```text
Profit per Branch = Profit / Branches
```

These KPIs help compare businesses of different sizes.

# 6️⃣ Customer Satisfaction Analysis

Customer satisfaction is analyzed by Business Type.

Metrics include:

* Average Satisfaction
* Maximum Satisfaction
* Minimum Satisfaction
* Number of Businesses

Example:

```sql
SELECT
    Business_Type,
    AVG(Customer_Satisfaction) AS Average_Satisfaction,
    MAX(Customer_Satisfaction) AS Max_Satisfaction,
    MIN(Customer_Satisfaction) AS Min_Satisfaction,
    COUNT(*) AS NumberOfBusinesses
FROM business_data
GROUP BY Business_Type
HAVING AVG(Customer_Satisfaction) > 4.0;
```

# 7️⃣ CTE Analysis

Common Table Expressions are used to make complex analytical queries easier to understand and maintain.

### Example: Businesses Above Their Business-Type Average Profit

```sql
WITH BusinessTypeAverage AS (
    SELECT
        Business_Name,
        Business_Type,
        Profit,
        AVG(Profit) OVER (
            PARTITION BY Business_Type
        ) AS AvgTypeProfit
    FROM business_data
)
SELECT
    Business_Name,
    Business_Type,
    Profit,
    AvgTypeProfit
FROM BusinessTypeAverage
WHERE Profit > AvgTypeProfit;
```

This identifies businesses performing above the average Profit of their own Business Type.

# 9️⃣ Top 3 Businesses by City

The project identifies the top 3 businesses based on Profit within each City.

```sql
WITH RankedBusinesses AS (
    SELECT
        Business_Name,
        Business_Type,
        City,
        Profit,
        DENSE_RANK() OVER (
            PARTITION BY City
            ORDER BY Profit DESC
        ) AS RankNumber
    FROM business_data
)
SELECT
    Business_Name,
    Business_Type,
    City,
    Profit
FROM RankedBusinesses
WHERE RankNumber <= 3;
```

`DENSE_RANK()` is used so that businesses with equal Profit receive the same rank.

# 1️⃣1️⃣ Profit Contribution Analysis

The project calculates how much each business contributes to the total Profit of its Business Type.

```sql
WITH BusinessTypeProfit AS (
    SELECT
        Business_Name,
        Business_Type,
        Profit,
        SUM(Profit) OVER (
            PARTITION BY Business_Type
        ) AS TypeTotalProfit
    FROM business_data
)
SELECT
    Business_Name,
    Business_Type,
    Profit,
    TypeTotalProfit,
    Profit * 100.0 / TypeTotalProfit
        AS ProfitContributionPercentage
FROM BusinessTypeProfit;
```

This helps identify businesses that contribute significantly to their Business Type's overall profitability.

# 1️⃣3️⃣ Running Profit Analysis

A running total of Profit is calculated after ordering businesses by Profit descending.

```sql
SELECT
    Business_ID,
    Business_Name,
    Business_Type,
    Profit,
    SUM(Profit) OVER (
        ORDER BY Profit DESC
        ROWS BETWEEN UNBOUNDED PRECEDING
        AND CURRENT ROW
    ) AS RunningTotalProfit
FROM business_data
ORDER BY Profit DESC;
```
